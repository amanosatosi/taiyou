# T010 hard-line layout candidate

Base: `86490f15738aaa0d712a7ff1786ec0fc5437909b`, merged T009. Main passed [Fast](https://github.com/amanosatosi/taiyou/actions/runs/39072624514), [Blueprint](https://github.com/amanosatosi/taiyou/actions/runs/39072624658) and [the native matrix](https://github.com/amanosatosi/taiyou/actions/runs/39072624650). This candidate remains unmerged for technical/shared-interface/native review. Historical independent-review debt and T005 trusted-validation/configuration gates are not closed by candidate CI.

`layout(&ShapedEvent, &LayoutConstraints)` returns immutable local script geometry. Hard lines retain decoded source ranges, baseline points, maximal ascent/descent, advance widths and explicit visual glyph ranges. Positions reference retained shaped run/glyph indices and evaluated style associations. All nine alignments use each line's logical width and total block height; margins, explicit event positions, viewport coordinates and raster offsets do not affect local layout. Paint metadata remains reachable through the retained input; geometry has no color fields. `geometry_eq` compares geometry while full structural equality also preserves source and metadata identity; it is not a cache key.

The minimal T009 data additions solve actual information gaps rather than estimate ink or blank-line height:

- `GlyphInk` distinguishes unavailable, empty and checked script-space bounds. The existing native adapter obtains HarfBuzz design-unit glyph extents, copies integer values and converts them once using the same font-size scale and y flip as glyph positions. No path or outline is extracted. Layout rejects unavailable extents rather than substituting an advance rectangle. Whitespace contributes advance without ink. Synthetic producers explicitly supply known extents or empty ink.
- Evaluated events retain terminal style, including override-only and empty events. Shaped empty lines retain actual selected-font metrics, identity and vertical scale. A blank line uses the style at its terminating break; a trailing blank line uses terminal style. Host-created empty events without explicit style/metrics fail. Line gaps are retained in font metrics but Core line height uses ascent plus descent under C4.
- Hard-line L1 bidi levels are prepared with the pinned Unicode analysis, including trailing whitespace. Paragraph-sized temporary analysis avoids a whole-event level-vector clone per line. Layout implements L2 on run groups after hard-line delimitation; HarfBuzz glyph arrays inside each group are preserved.

Fallback metrics are retained for every native font group. Line ascent/descent use their maxima after local scale, and baselines accumulate these heights. Glyph offsets affect ink and collision bounds, not typographic ascent/descent. Logical boxes use advance widths including whitespace. Ink is the union of actual positioned glyph bounds; no-ink lines use `None`. The collision envelope unions logical and ink boxes, without border/effect inflation or collision adjustment. Font bounds are unhinted design-space ink bounds, not raster coverage.

Core spacing in this candidate adds one contribution per shaped cluster advance, including its terminal cluster; multiple glyphs within a cluster add spacing once. Exact synthetic cases expose this initial Core choice for technical review; no Legacy spacing claim is made. A scale change inside a shaped cluster is explicitly unsupported rather than assigning invented character positions. Uniform scales and size changes between shaped runs are supported. Non-2 wrapping, Legacy metrics, automatic wrapping, outlines, rasterization, effects and event collision resolution remain outside T010.

Geometry operations reject nonfinite results and extent overflow. Layout preflights checked glyph/line/workspace arithmetic, checks configured text/glyph/transient/dimension caps, and uses fallible vector reservations. Publication verifies map ownership, line ranges, glyph references and associations. Existing native allocation estimates remain admission checks, not a hard process-RSS guarantee. No new dependency or unsafe exception is introduced; the glyph-extents POD gets additional ABI checks in the existing adapter/header tests.

Tests: `layout_numeric` uses independently calculated synthetic expectations for all nine anchors, mixed fallback metrics, exact baselines, empty/break-only events, whitespace, negative offsets/mark ink, native-array-preserving visual order, scaling/spacing, paint independence, repeated results and failure limits. `layout_fixed_font` uses PR 17's unchanged pinned Latin/Arabic/Indic/CJK inputs for real metrics, fallback, bidi/L1, ink and retained ownership. CLI `layout_pipeline` exercises actual ASS parsing, evaluation, shaping and layout, including all three escapes, noncontiguous ligature provenance, terminal size changes and empty events. Existing expected assets and reference tolerances are unchanged. Fixed-font floating accumulation checks allow only arithmetic-rounding error; exact synthetic expectations and existing shaping goldens remain exact.

All compilation and tests execute on GitHub Actions. The PR records exact final SHA and focused/full run/job links, including workspace Clippy/tests, DAG and unsafe guards, Windows MSVC, Linux and macOS ARM64, exact MSRV and existing native sanitizer checks. This is not performance evidence or independent review. T011 requires accepted integration and a separate assignment; it is not implemented here.
