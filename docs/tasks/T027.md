# T027 — Usable single-worker headless renderer integration

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Integrate the supported ASS/SSA feature set into a documented headless tool before parallelism.

## Prerequisites

[T019](T019.md), [T020](T020.md), [T021](T021.md), [T022](T022.md), [T023](T023.md), [T026](T026.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Extend planned cli/render.rs and renderer integration tests; create docs/USAGE.md and supported-capabilities report from approved registry. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C7 transactional errors, explicit fonts/profile/limits, diagnostics and output lifetime. Add deterministic batch timestamp input and JSON reports; retain the T014 CLI flags. Batch seeks reuse renderer safely; output filenames cannot silently overwrite inputs. Export declared unsupported features and dependency versions.

## Expected behavior

Render a fixed sequence and the same times shuffled: each timestamp image matches; strict unsupported fails with nonzero status; malformed frame request produces no partial image. PNG/raw metadata identify premultiplication/profile.

## Implementation guidance

This is integration, not missing-feature implementation. Every missing capability routes to its task/research gate. Do not broaden scope labels to meet milestone.

Read [GOALS](../GOALS.md#g2-initial-usable-renderer). Read [CONTRACTS](../CONTRACTS.md#c7-renderer-errors-and-limits).

## Acceptance criteria

G2 single-worker subset passes on three OS targets with fixed fonts; complete compatibility report and usage examples exist. No unresolved crash or formerly passing regression.

## Verification

Run cargo test --workspace, all supported comparisons, CLI batch/backward-seek/error smoke and platform builds. Publish full report including unsupported/infra counts. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No multithreading, new ABI promises, hidden automatic profile selection or reference edits. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.

## Completion report

Report T027, integration base and commit IDs (or explicitly no Git), changed files, exact commands and pass/fail results, fixture/profile/source revisions, unsupported cases, limitations and follow-up IDs. Attach stage/image/report evidence required above. For measured changes provide raw before/after samples and environment; otherwise state no performance claim. Record any acceptance gate still open; do not mark the task complete when required evidence is missing.
