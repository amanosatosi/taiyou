# T007 — Static tag evaluation and active event selection

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Evaluate the static Core text state at an absolute time without shaping or drawing.

## Prerequisites

[T006](T006.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/evaluate.rs and tests/evaluate.rs; introduce only corresponding shared evaluated types through coordinator review. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C3 ordered evaluation, style reset, paint/geometry separation and independent change flags. Select start-inclusive/end-exclusive active events. Preserve source ordinal for composition. Strict mode errors on Unsupported; tolerant mode reports it. Reset named/unnamed style without resetting clock.

## Expected behavior

At start event appears, at end it disappears; red A followed by reset B uses default white B; color changes do not change ShapeStyle; backward timestamps give same state as fresh evaluator.

## Implementation guidance

C3 and K3. Keep event selection deterministic; no previous-frame mutation.

Read [CONTRACTS](../CONTRACTS.md#c3-evaluation-and-dependency-classification). Read [CACHING](../CACHING.md#k3-change-matrix).
