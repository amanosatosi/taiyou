# T010 — Hard-break layout and alignment

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Lay out shaped runs with hard breaks, Core WrapStyle2 and nine alignments.

## Prerequisites

[T009](T009.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/layout.rs and tests/layout.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C4 local baselines, distinct logical/ink/collision boxes and empty-line metrics. Output is relative to an alignment anchor; no absolute position or collision mutation. Use maximal line ascent/descent, include whitespace advances, no ink for spaces. Preserve per-line visual order and clusters.

## Expected behavior

Two hard-separated lines have predictable baselines; alignment2 centers the logical block at bottom anchor; alignment7 places top-left; blank middle line consumes style line height. N and n behavior matches Core wrap2.

## Implementation guidance

Use synthetic ShapedRun inputs for exact numeric tests, then fixed-font integration. No automatic wrap modes yet.

Read [CONTRACTS](../CONTRACTS.md#c4-font-resolution-shaping-and-layout).

## Acceptance criteria

All nine anchors and empty/space-only lines pass exact geometry tests. Paint changes leave layout equal.
