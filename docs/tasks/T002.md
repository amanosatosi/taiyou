# T002 — Freeze dependency and native build recipes

Status: planned. Suggested owner: **Sol 6.1; Astra review**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Produce reproducible Windows/Linux/macOS dependency recipes and a reviewed dependency inventory.

## Prerequisites

[T001](T001.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned rust-toolchain.toml, Cargo.lock, docs/DEPENDENCIES.md, THIRD_PARTY_NOTICES.md and native build recipe files under build-support/. Modify only relevant manifests. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

Select exact stable Rust/MSRV and maintained binding versions for HarfBuzz, FreeType, Unicode bidi/script analysis; optional Rayon and PNG stay off until their task. HarfBuzz OpenType shaping uses immutable bytes; FreeType supplies unhinted outlines/gray raster. Prefer build-from-pinned-source native recipes for reference CI. Record SHA-256, source URL, flags, license choice, transitive dependencies, static/dynamic linkage and notices. Owner licensing decision is required before distribution, not before CI tests. Generate Cargo.lock and native build outputs on Actions runners; retrieve only small reviewed lockfiles/reports for repository inclusion, not build caches or toolchains.

## Expected behavior

The same pinned font can be loaded and its glyph count queried through a temporary build smoke program on all three OS families; build recipe reports actual library versions. No dependence on an arbitrary host-installed version.

## Implementation guidance

ADR-002 and S4. This is a bounded dependency audit, maximum two focused sessions; unresolved bindings/licensing become an architect decision with two concrete alternatives. Do not adopt an abandoned library solely because it is pure Rust.

Read [SOURCES](../SOURCES.md#s4-license-and-reuse-policy). Read [decisions/002-font-and-raster](../decisions/002-font-and-raster.md).

## Acceptance criteria

Lockfile and native hashes are complete, three platform smoke results are captured, dependency obligations and maintenance checks are reviewed. No placeholder hashes or mutable branch pins.

## Verification

**Execution:** Run compiler/Cargo/native builds and test executables in GitHub Actions, never on the user's PC. Only lightweight documentation/hash checks may run locally. Follow the [CI-first policy](../DEVELOPMENT.md#d0-execution-location-and-local-storage) and report candidate SHA plus Actions run/job links; unrun checks remain pending.

Run locked workspace build and native version smoke on Windows MSVC, Linux and macOS ARM64. Record commands in DEPENDENCIES.md; verify clean rebuild from cache miss. Run cargo tree and archive license/advisory review. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No libass runtime dependency, GPL xy source reuse, shaping algorithm implementation or reference output updates. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
