# T013 — Scalar paint and ordered RGBA composition

Status: planned. Suggested owner: **Luna 6**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Implement exact Core solid paint and source-over into owned RGBA buffers from synthetic masks.

## Prerequisites

[T003](T003.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/{paint,compose}.rs and tests/blend.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C6 byte order, mul255 and multiplication order, half-open clipping, premultiplication and DrawOrder. Implement single-worker row traversal only. Validate extents/strides, transparent black initialization and checked output budget.

## Expected behavior

128-alpha red over opaque blue gives128,0,127,255; over clear gives128,0,0,128; transparent paint leaves destination unchanged; reversing two translucent ops changes output and must not be optimized away.

## Implementation guidance

C6 is the oracle. Use hand-computed tiny images, not generated goldens to approve implementation arithmetic.

Read [CONTRACTS](../CONTRACTS.md#c6-paint-composition-and-output).

## Acceptance criteria

Exhaustive mul255 for all u8 pairs and bounded source-over tests pass; negative/offscreen mask coordinates and stride padding handled safely.

## Verification

Create blend_exact, blend_order, compose_bounds and output_limit tests. Run cargo test -p taiyou-render blend and cargo test -p taiyou-render compose. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No floating-point blending, gamma conversion, SIMD, tile parallelism, new pixel format or changes to rounding. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
