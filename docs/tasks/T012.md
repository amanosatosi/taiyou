# T012 — Scalar baseline fill raster adapter

Status: planned. Suggested owner: **Sol 6.1; native review**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Render transformed Core nonzero contours into immutable A8 masks using FreeType grayscale raster.

## Prerequisites

[T011](T011.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/raster.rs and tests/raster.rs; extend native raster adapter only. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C5 bounds/stride/zero-padding, Q6 inputs, fractional phase and group policy. No LCD/hinting/embedded bitmap. Preflight checked bounds and allocation reservations; empty/offscreen cases remain valid without huge allocations. Record raster backend version.

## Expected behavior

Integer-aligned full unit square has full coverage for its pixel; empty contours produce empty mask; fractional translations produce deterministic edge coverage; overlapping same-group contours follow nonzero winding.

## Implementation guidance

ADR-002. This proves a baseline only; do not call it xy-compatible. Preserve full effect-required source support rather than clipping paths prematurely.

Read [CONTRACTS](../CONTRACTS.md#c5-geometry-stroke-raster-and-effects). Read [TESTING](../TESTING.md#v3-image-comparison).
