# T008 — Font catalog and native context ownership

Status: planned. Suggested owner: **Sol 6.1; unsafe review**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Load host-supplied font bytes into immutable catalog records and private native contexts.

## Prerequisites

[T002](T002.md), [T003](T003.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-font/src/{catalog,native}.rs and tests/catalog.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

FontId includes content SHA-256 and collection face index. Preserve catalog registration order, validate face index and byte budget, own font-byte lifetime. Each FontContext creates/destroys its FreeType library/faces locally; native handles do not escape. Family comparison uses Unicode default case folding without locale and no compatibility-normalization substitution; T002 supplies the reviewed library or audited bounded name helper.

## Expected behavior

Two equal-name different fonts have distinct IDs; same bytes/index deduplicate; out-of-range TTC index errors; catalog byte-limit rejection does not corrupt existing catalog. Requested family resolution tie follows C4.

## Implementation guidance

C4/C8 and ADR-002. Keep filesystem discovery out. Use explicit licensed fonts from validation manifest; do not bundle unknown fonts.

Read [CONTRACTS](../CONTRACTS.md#c4-font-resolution-shaping-and-layout). Read [CONTRACTS](../CONTRACTS.md#c8-concurrency-and-cache-boundary).

## Acceptance criteria

Native lifetime and catalog-order tests pass, version info is exposed, no unsafe Send/Sync added and failed initialization cleans up.

## Verification

Create load/drop/reload, invalid-font, collection-index, font-byte retention and tie-order tests. Run cargo test -p taiyou-font; native sanitizer smoke per T002 recipe. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No system font search, shared FT_Face, custom font parser, rendering or silent fallback to an installed font. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
