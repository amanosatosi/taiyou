## Objective

Implement k/K/kf/ko timing and paint/outline selection for approved profile rules.

## Prerequisites

## Files and modules

Extend planned ass/overrides.rs and render/{evaluate,paint}.rs; create tests/karaoke.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

Karaoke centiseconds map to immutable logical syllable spans with cumulative checked times. Retain cluster boundaries and glyph positions; k switches primary/secondary at syllable start, K/kf sweeps within syllable duration, ko suppresses pre-highlight outline per approved R001 rule. R001 specifies RTL sweep and cluster splits before enabling them.

## Expected behavior

10-centisecond syllable lasts100,000us; previous syllables stay highlighted; zero duration switches without division; ligature/combining cluster is not byte-sliced; color progression reuses geometry unless grouping/outline selection changes.

## Implementation guidance

Use single glyph then multi-cluster and bidi fixtures. Represent sweep as paint/coverage partition, not reshaping every frame.

Read [CONTRACTS](../CONTRACTS.md#c3-evaluation-and-dependency-classification). Read [CONTRACTS](../CONTRACTS.md#c6-paint-composition-and-output).
