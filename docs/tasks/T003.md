# T003 — Typed units, errors and immutable IR subset

Status: planned. Suggested owner: **Luna 6; shared interface review**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Implement shared checked types needed by parser and the static vertical slice.

## Prerequisites

[T001](T001.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-types/src/{units,error,track,scene}.rs and tests/contracts.rs; update only types lib.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

Implement C1/C2/C7 types and constructors, static Style/Event/TextOp subset, limits and diagnostic codes; do not add future enum variants without their task. TimeUs checked conversion, FiniteF64 canonical zero, Q6 rounding/floor phase, half-open PixelRect. Expose no unchecked public constructors for bounded values. Track IDs are allocated by a documented ingestion owner and never recycled within a renderer session.

## Expected behavior

1:02:03.45 converts to 3,723,450,000 us; Q6 -1 splits (-1,63); NaN rejected; &H800000FF maps to red opacity127; zero-area rectangle is empty. Cloned Track shares immutable storage.

## Implementation guidance

C1/C2/C7 are normative. Standard library only. Include type docs with units, bounds and ownership.

Read [CONTRACTS](../CONTRACTS.md#c1-units-arithmetic-and-identity). Read [CONTRACTS](../CONTRACTS.md#c2-input-and-immutable-ir).

## Acceptance criteria

Constructor, overflow, color, interval and identity tests pass; no mutable shared outputs or unresolved unit ambiguity. Architect approves exported types before dependents branch.

## Verification

Create tests for exact examples, boundaries, overflow, negative time, ties and byte spans. Run cargo test -p taiyou-types and cargo clippy -p taiyou-types -- -D warnings. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No parser, renderer, unsafe code, native dependencies, guessed legacy defaults or contract changes. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
