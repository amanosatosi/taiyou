# T011 — Owned glyph paths and 2D geometry mapping

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Extract unhinted owned glyph outlines and map basic placement/scale/z rotation to Q6 device paths.

## Prerequisites

[T010](T010.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/geometry.rs; add font outline adapter and tests/geometry.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C5 path commands, nonzero winding, y-up to y-down once, Core matrix order, default/explicit origin and fractional phase factoring. Native extraction flags from T002; copy commands before releasing face/context. No perspective/shear yet.

## Expected behavior

Identity mapping preserves expected bounds; positive90 rotation sends a rightward vector upward; integer translation preserves local contour+phase; -1 Q6 tick has phase63; empty glyph gives empty outline.

## Implementation guidance

C1/C5. Start with synthetic paths to avoid confounding font metrics. Reject nonfinite/overflow coordinates before raster.

Read [CONTRACTS](../CONTRACTS.md#c5-geometry-stroke-raster-and-effects). Read [CACHING](../CACHING.md#k2-exact-key-dependencies).

## Acceptance criteria

Transform/order/rounding/ownership tests pass. Color is absent from outline keys and values.

## Verification

Create exact square/curve transform tests plus one glyph extraction lifetime test; run cargo test -p taiyou-render geometry and cargo test -p taiyou-font. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No bespoke shaping, color in geometry, perspective guesses, custom raster algorithm or GPL translation. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
