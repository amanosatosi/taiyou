# T021 — ASS vector drawings and independent clipping

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Lower ASS drawing commands and rect/vector clips to color-free geometry and clip coverage.

## Prerequisites

[T011](T011.md), [T018](T018.md), [R001](R001.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned ass/drawing.rs, render/{drawing,clip}.rs and tests/drawing_clip.rs; extend only approved IR variants. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C5 coordinate scale, baseline and fill rule; R001 specifies m/n/l/b/s/p/c grammar/closure and malformed recovery before enabling each command. Rect/path inverse clips operate in script/device map independent of text transforms. Clip multiplies effected coverage at compose; do not preclip blur.

## Expected behavior

p1 coordinates unscaled, p2 halved; clip stays stationary when text moves/rotates; inverse rectangle shows only outside; an offscreen clip yields empty output without huge buffer; blur crossing clip edge is cut after blur.

## Implementation guidance

Parser and path conversion can be separate commits but one owner for shared enum. Bound segments and spline tessellation; do not guess B-spline semantics.

Read [CONTRACTS](../CONTRACTS.md#c5-geometry-stroke-raster-and-effects). Read [CACHING](../CACHING.md#k3-change-matrix).

## Acceptance criteria

Command fixtures, fill holes, inverse/noninverse, fractional edges and post-blur clipping pass; source masks unchanged across clip animation.

## Verification

**Execution:** Run compiler/Cargo/native builds and test executables in GitHub Actions, never on the user's PC. Only lightweight documentation/hash checks may run locally. Follow the [CI-first policy](../DEVELOPMENT.md#d0-execution-location-and-local-storage) and report candidate SHA plus Actions run/job links; unrun checks remain pending.

Create drawing_scale, path_grammar, clip_independence, inverse_clip and blur_clip_order tests. Run focused comparisons and stage unit suites. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No arbitrary path language, file I/O in drawings, text-transform inheritance for clip, unsupported morphing or source-mask mutation. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
