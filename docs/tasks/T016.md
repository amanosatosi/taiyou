# T016 — Borders and shadows

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Render static borders and shadows with correct grouping and ordered passes.

## Prerequisites

[T014](T014.md).

## Files and modules

Create planned crates/taiyou-render/src/stroke.rs; extend raster/scene and tests/borders_shadows.rs using source-backed behavior. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

Implement C5 while correcting ordinary ASS behavior to verified pinterf semantics. Width/offset coordinate spaces are explicit; shadow fractional offset affects raster phase. Fill, outline and shadow masks remain separate from paint. Coverage subtraction/group rules cannot be invented.

## Expected behavior

Border0 produces no outline; shadow0 coincides spatially but respects pass order; transparent fill does not leave a filled border interior; overlapping glyphs and rotated bordered text match approved fixtures. Zero-axis/anisotropic forms require direct pinterf verification before implementation.

## Implementation guidance

Keep fill raster cache identity independent of border width where policy permits.

Read [CONTRACTS](../CONTRACTS.md#c5-geometry-stroke-raster-and-effects). Read [CACHING](../CACHING.md#k3-change-matrix).
