# T025 — Deterministic tile composition

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Compose disjoint output tiles in parallel without reordering or truncating effects.

## Prerequisites

[T024](T024.md), [T013](T013.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Extend planned render/compose.rs and scheduler.rs; create tests/tile_composition.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

A5/C6 stable full DrawOrder traversal builds tile operation lists; one mutable pixel region per task; no atomics/reductions. Effects already computed with full halo. R003 selects production tile size; tests expose alternatives without changing arithmetic.

## Expected behavior

Two translucent events crossing four tiles match scalar output byte-for-byte; inverse clips and blur halos have no seams; empty tiles stay transparent; tile sizes16/32/64/128 produce identical bytes.

## Implementation guidance

Use safe disjoint slices or narrowly reviewed row partition helpers; do not construct overlapping mutable views. Group small tiles using R003 thresholds.

Read [CONTRACTS](../CONTRACTS.md#c6-paint-composition-and-output). Read [ARCHITECTURE](../ARCHITECTURE.md#a5-execution-and-determinism).
