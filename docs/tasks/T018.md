# T018 — Bounded scalar blur and edge blur

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Implement Core scalar filters and approved legacy effect policy with full halo support.

## Prerequisites

[R002](R002.md), [T016](T016.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/effects.rs and tests/effects.rs; extend override/evaluation only for approved blur/be fields. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C5 coefficient quantization, zero exterior, per-pass rounding and finite support; R002 governs legacy mappings/pass selection. Allocate full expanded mask before filtering and keep source immutable. Limits on radius/pass count fail deterministically.

## Expected behavior

blur0/be0 returns equal coverage; impulse kernel is symmetric and bounded; blur crossing image/tile edges loses no halo before final clip; oversized sigma errors instead of truncating; cache source mask is unchanged.

## Implementation guidance

Start with separable scalar row/column passes and scratch reuse. Compare analytic impulse/small masks before glyph images; no SIMD or row parallelism.

Read [CONTRACTS](../CONTRACTS.md#c5-geometry-stroke-raster-and-effects). Read [TESTING](../TESTING.md#v6-determinism-and-cache-tests).

## Acceptance criteria

Kernel sum/support/rounding and border-shadow selection tests pass; checked allocation failures leave no partial frame.

## Verification

Create impulse, constant_interior, zero_border, pass_rounding and limit tests; run approved xy effect fixtures and cargo test -p taiyou-render effects. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No approximate box blur replacement, output tolerance changes, tile-local truncated blur or color in filter cache. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.

Attach stage/image/report evidence required above. For measured changes provide raw before/after samples and environment; otherwise state no performance claim. Record any acceptance gate still open; do not mark the task complete when required evidence is missing.
