# T014 — Single-worker vertical slice CLI

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Connect the existing stages to render a minimal ASS file at a requested time to raw RGBA and PNG.

## Prerequisites

[T007](T007.md), [T010](T010.md), [T012](T012.md), [T013](T013.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned crates/taiyou-render/src/renderer.rs and crates/taiyou-cli/src/render.rs; integration fixtures under tests/taiyou/core-slice/. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

Expose C7 render with workers=1, strict/tolerant capability handling and owned Frame lifetime. CLI interface: taiyou render --input FILE --font FILE (repeatable) --time-us N --width W --height H --profile core-v1 --output FILE.png; add --raw FILE.rgba for exact comparisons. Font order is flag order. PNG conversion is C6. Introduce audited PNG dependency through T002 policy.

## Expected behavior

One fixed-font event appears only in active interval; pos/align/color/hard breaks render; unsupported blur in strict mode fails clearly; no active event yields full transparent frame; backward seek repeats exact bytes.

## Implementation guidance

A4 and G1. CLI reports unsupported diagnostics and version/profile; no GUI/video decoder. Cache is off; workers>1 is an explicit unsupported configuration until T024.

Read [GOALS](../GOALS.md#g1-vertical-slice). Read [CONTRACTS](../CONTRACTS.md#c7-renderer-errors-and-limits).

## Acceptance criteria

End-to-end fixture has independently reviewed expected geometry/pixels, timing/error cases pass, output lifetime is verified. This is the first drawable slice, not general ASS support.

Run cargo test --workspace and blueprint checker. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.
