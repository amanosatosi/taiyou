# T029 — Reproducible KFX and performance corpus

Status: planned. Suggested owner: **Sol 6.1**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Establish measurable cold/warm and real-world KFX workloads with stage/work/memory counters.

## Prerequisites

[T027](T027.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned benches/, validation/performance.json and xtask/src/bench.rs. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

V8 corpus provenance and hashes, exact timestamps/dimensions/features, independent correctness verification. Counters include stage duration, construction count, pixels, allocation volume, accounted bytes and native RSS. No benchmark threshold until R003.

## Expected behavior

Same run configuration reproduces exact output hashes; a color-only KFX sequence shows unchanged outline construction after warmup; cold run resets retention explicitly, warm run records preparation. Missing licensed corpus is reported rather than substituted silently.

## Implementation guidance

Include synthetic stress fixtures and authorized real-world samples. Comparison to other renderers requires equivalent supported output and separately recorded environments.

Read [TESTING](../TESTING.md#v8-performance-and-kfx). Read [GOALS](../GOALS.md#g3-performance).

## Acceptance criteria

Runnable benchmark command produces schema-validated raw samples plus configuration; all workloads have correctness hashes/profiles and asset permissions.
