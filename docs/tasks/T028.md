# T028 — C ABI v1 and lifetime validation

Status: planned. Suggested owner: **Sol 6.1; Astra ABI/unsafe review**. Scope: one focused implementation session unless explicitly bounded as research; split with coordinator approval if unexpected work appears.

## Objective

Implement and freeze the opaque-handle ABI after public rendering behavior stabilizes.

## Prerequisites

[T025](T025.md), [T027](T027.md). These must meet their acceptance gates before dependent work starts.

## Files and modules

Create planned include/taiyou.h, crates/taiyou-capi/src/{handles,api}.rs, tests/capi/ C/C++ consumers and docs/C_API.md. All creation paths in this section are planned; inspect for intervening implementations before editing.

## Technical contract

C9 names/status/lifetimes, size/version prefixes, fixed-width fields, caller-buffer diagnostics, copied input ownership, null-on-error and no unwind crossing. Complete exact field layout table before coding, reviewed by architect. Append-only compatible struct growth, exported-symbol allowlist and semantic version policy.

## Expected behavior

Frame stays valid after later render and renderer/track/catalog release; release(NULL) safe; bad struct size/version/null+length rejects; data view reports RGBA premult format. Invalid arbitrary pointers are documented caller errors, not promised recoverable.

## Implementation guidance

Use safe internal handles around validated C boundaries; all release/use external synchronization explicit. Do not expose Rust enum/layout.

Read [CONTRACTS](../CONTRACTS.md#c9-c-abi-contract). Read [decisions/006-output-and-ffi](../decisions/006-output-and-ffi.md).

## Acceptance criteria

C and C++ consumers build/run on all three OS families; lifetime/error/panic-boundary tests pass; header/export ABI snapshot reviewed before v1 designation.

## Verification

Run cargo test -p taiyou-capi, compile/link C/C++ smoke per platform, sanitizer lifetime tests, exported symbol and struct size/offset checks,32-bit checked-length tests where target available. Commands referring to Cargo/xtask are established by the task that creates that tooling; do not report them run before it exists.

## Forbidden changes

No libass ABI impersonation, borrowed output until next frame, caller freeing Rust allocations, hidden last-error TLS or ABI freeze without review. Ordinary implementation cannot modify protected expected assets, tolerances or support classifications.
