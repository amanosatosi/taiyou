## Explicit prerequisite for T009: decoded-source provenance

The static evaluator is preserved. Its literal runs retain exact original UTF-8 byte spans, but a decoded `HardBreak`, `SoftBreak` or `NoBreakSpace` currently retains only the containing event span. That is coarse provenance, **not** an individual character/escape span. Decoded byte/scalar offsets also differ from original offsets after escapes, overrides, BOMs and multibyte text. T009 cannot report clusters by adding decoded offsets to an event span or by assigning that span to every character.

Before T009 shapes decoded runs, implement and review an explicit decoded-text-to-original-source interval map. Preserve original byte ranges through tokenization, decoding, run joining and cluster construction; retain the mapping across paint/style boundaries. Tests must include `\N`, `\n`, `\h`, UTF-8 multibyte and combining text, BOM/CRLF input, and override blocks between characters. A host-created spanless unit has no recoverable exact source position: obtain explicit provenance through a reviewed input/IR extension or report the missing provenance rather than fabricating a range. Any shared IR extension follows the existing contract/architect review gate. Accurate original-source cluster provenance and these regressions are prerequisites for T009 acceptance; no T009 code or new mapping is implemented in T007.
